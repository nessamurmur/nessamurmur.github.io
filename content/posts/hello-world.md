Welcome to my blog! This is my first post using **njssg**, a static site generator built with Gleam.

## Why Gleam?

Gleam is a friendly language for building type-safe, scalable systems. It compiles to Erlang and JavaScript, making it versatile for both backend and frontend development.

## Features of njssg

This static site generator includes:

- Markdown content with TOML frontmatter
- Category support for organizing posts
- RSS feed generation
- Tailwind CSS for styling
- Development server with live reload

## Code Example

Here's a simple Gleam function:

```gleam
pub fn greet(name: String) -> String {
  "Hello, " <> name <> "!"
}
```
